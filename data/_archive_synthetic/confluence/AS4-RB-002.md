## Symptoms
Invoices do not print; spool files show RDY status on output queue PRT01; message CPA3394 or writer PRT01 ended.

## Resolution
1. Check the writer with `WRKWTR WTR(PRT01)`. Answer any pending message on QSYSOPR.
2. Ping the printer with `PING RMTSYS('10.20.4.51')`. If unreachable, raise a ticket with the network team.
3. Restart the writer with `STRRMTWTR OUTQ(PRT01)`.
4. Confirm spool files move from RDY to WTR status in `WRKOUTQ OUTQ(PRT01)`.

## Verification
Invoices print and the output queue drains.
