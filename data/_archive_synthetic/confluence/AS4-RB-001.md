## Symptoms
Batch jobs remain in JOBQ status; users report the nightly order import has not run.

## Diagnosis
1. Run `WRKJOBQ JOBQ(WHSLIB/WHSJOBQ)` and check whether the queue status is HLD.
2. Run `WRKSBS` and check that subsystem WHSBATCH is active.

## Resolution
1. If the queue is held, release it with `RLSJOBQ JOBQ(WHSLIB/WHSJOBQ)`.
2. If WHSBATCH is not active, start it with `STRSBS SBSD(WHSLIB/WHSBATCH)`.
3. If jobs are individually held, release them with `RLSJOB` after confirming with the batch owner.

## Verification
Jobs move to ACTIVE status and complete.
