## Symptoms
User cannot sign on (CPF1394, profile disabled) or gets CPF2189 not authorised to an object in WHSLIB.

## Resolution
1. Verify the request is approved in the access management tool before any change.
2. Re-enable a disabled profile with `CHGUSRPRF USRPRF(<user>) STATUS(*ENABLED)` and ask the user to reset their password through the self-service portal.
3. For object authority errors, do not grant authority directly; add the user to the WHSUSERS group profile through an access request.

## Verification
The user can sign on and open the warehouse menu.
